## Confirmed requirements

- Deadline remains **2026-10-30 10:00 PDT**, equivalent to **14:00 ART**.
- The project must run on Nebius Token Factory or Nebius AI Cloud and use at least one NVIDIA open-source model.
- A Token Factory runtime inference call satisfies the Nebius runtime definition.
- Submission requires a working demo URL, public open-source repository with a visible license and reproducible README, English materials or English translations, and a public YouTube demonstration under three minutes.
- The overview asks the video audio to explain the use of Nebius Token Factory and the NVIDIA model.
- Judges must be able to access the project free of charge and without restriction through the judging period, which ends **2026-12-15 12:00 PST**.
- Feedback on the Nebius/NVIDIA tools used is a required submission field.
- Best Use of Tavily requires a functional runtime Tavily API call; an unused adapter is insufficient.
- Human interviews or an independently validated benchmark are not official eligibility requirements.

## Judging implication

The official rules currently describe four **equally weighted** criteria:

1. technological implementation;
2. design;
3. potential impact;
4. quality of the idea.

The submission therefore cannot compensate for a weak live Nemotron integration with evaluation paperwork alone. The demo must divide its proof across all four criteria: a real model call, a coherent mobile workflow, a credible post-storm operational problem, and the non-obvious “evidence sufficiency before action” boundary.
